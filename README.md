# Marvio feedback

Found a bug in [Marvio](https://marvio.io), or have an idea that would make it better? Tell us here.

1. Go to **Issues → New issue**.
2. Choose **Bug report** or **Idea**.
3. Fill in the form. Screenshots help a lot.

Everything you post here is **public**. Please don't include passwords, access tokens, or your customers' private data.
